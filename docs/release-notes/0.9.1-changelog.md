# Manifold 0.9.1 — detailed changelog (internal)

Internal record for the 0.9.1 release. Not for testers or the website: it names commits, files and measurements. The
user-facing notes are `docs/release-notes/0.9.1.md`.

Commits since `53b4bee` (0.9.0, build 21, the build that shipped), grouped by area. "Visible?" says whether a user would
notice. The release commit itself (version 0.9.1, build 22, these notes) and the accessibility-names commit just before it
are the last two on top of `b1871b8`.
