# Manifold 0.9.0 — detailed changelog (internal)

Internal record for the 0.9.0 release, moved out of `RELEASE_NOTES.md` on 2026-10-29 so the update
dialog's section holds only its bullets. Not for testers or the website: it names commits, files
and measurements. The user-facing notes are `docs/release-notes/0.9.0.md`.

Commits since `4114995` (0.8.4, build 19, the build that shipped), grouped by area. "Visible?" says whether a user would notice;
**Unsure** rows carry the reason and need a decision before release.
