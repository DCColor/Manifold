# Manifold 0.9.1

**Version 0.9.1 (build TBD) · Date TBD · Beta for testers**

## Summary

0.9.1 fixes how HDR is shown in the window. HLG and PQ now look right in both display modes. As macOS
Shows It now matches QuickTime for HLG and PQ, including on a display in SDR mode. Reference now shows
HLG correctly: in 0.9.0 it was far too bright. SDI and HDMI output, the scopes and exported frames are
unchanged.

## Highlights

- **HDR in As macOS Shows It matches QuickTime.** HLG and PQ are now handed to macOS's own HDR
  handling, so bright highlights roll off instead of clipping to white.
- **HLG in Reference is fixed.** It was shown far too bright in 0.9.0. It now follows the broadcast
  standard, with HLG's reference white at 203 nits.
- **Nothing changes on SDI or HDMI.** The output, the scopes and exported frames are exactly as in 0.9.0.

## Improved

### Color

- **HLG in As macOS Shows It.** Manifold now hands an HLG picture to macOS's HLG adjustment, as
  QuickTime does. On a display in SDR mode, an iPhone HLG clip no longer clips faces, white shirts and
  sky to white. With HDR on, the picture matches QuickTime by eye.
- **PQ in As macOS Shows It.** Manifold now hands a PQ picture to the macOS HDR10 tone map, as
  QuickTime does. It uses the file's mastering brightness when the file declares it, and macOS's
  defaults when it doesn't. On a display in SDR mode, PQ was about twice as bright as QuickTime and
  clipped everything from 100 nits up. It now matches QuickTime on every grey step. With HDR on, it
  matches QuickTime by eye.
- **This follows the picture, not just the source.** A LUT whose output is set to PQ or HLG is treated
  the same way. A PQ or HLG source under a LUT that outputs Rec. 709 is not.
- **The scopes still show the file.** In As macOS Shows It, macOS now adapts HLG and PQ to your display,
  so above the display's limit the window and the scopes no longer agree. The picture also changes with
  the display's HDR headroom and, for HLG, its brightness. The transform chain readout says so, for
  example "macOS HLG adjustment · follows display brightness · scopes show the file".
- **Reference is absolute for HDR.** In Reference, PQ and HLG are shown as absolute light: 1.0 on the
  display is 100 nits, with no tone mapping. Above what the display can show, the picture clips. On a
  display in SDR mode, the readout now says "display in SDR mode · above 100 nits clips", for PQ and HLG
  alike. PQ in Reference looks the same as in 0.9.0. SDR in Reference is unchanged (BT.1886).
- **Hold to compare means more for HDR.** As macOS Shows It and Reference now differ for HLG and PQ, so
  holding C shows what macOS's tone mapping does to the picture.

## Fixed

### Color

- **HLG in Reference was far too bright** (a bug in 0.9.0 and earlier). HLG at 50 % was shown at SDR
  white, and everything above it clipped. Reference now converts HLG to PQ as the broadcast standard
  (BT.2408) says, at 1000 nits. HLG's reference white (75 %) now lands at 203 nits, the same as PQ's.
  On a display in SDR mode, clipping now starts at about 63 %, as a PQ picture clips at 100 nits.

### SDI/HDMI output

- **No change.** These fixes change only what the window shows. SDI and HDMI output, the HDR signal sent
  with it, the scopes and exported frames are identical to 0.9.0 in every display mode.

### Live streams

- **Install NDI Runtime… could fail to download.** NDI's short link stopped working. The button and the
  menu item now download the installer directly, and a link to NDI's own downloads page sits beside them
  in case the file ever moves.

### Files and interlaced

- **Confirmed on a MacBook Air:** the iPhone rotation fix in 0.9.0 build 21 works. Clips open the right
  way up, and a vertical window can be made smaller.

## Known limitations

### Color

- **Very saturated PQ colors in As macOS Shows It differ slightly from QuickTime.** Colors far outside
  your display's range, such as a bright Rec. 2020 green or cyan, can look a little brighter in Manifold
  than in QuickTime. Colors your display can show match.
- PQ or HLG on primaries other than Rec. 2020 or P3-D65 still can't be shown as stated (as in 0.9.0).

### SDI/HDMI output

- Over HDMI, an HLG picture still goes out without its HLG signal, so the display isn't told to switch
  to HLG. SDI carries HLG. (Unchanged from 0.9.0.)

### Interface and shortcuts

- In a narrow or vertical window, the control bar doesn't adapt to the width, and the resolution
  overlay is badly placed.

## For testers: what to look at

- **HDR in As macOS Shows It against QuickTime,** with HLG (including iPhone clips) and PQ, on a display
  in SDR mode and with HDR on. Does Manifold look like QuickTime?
- **HLG in Reference.** Highlights should no longer be blown out the way they were in 0.9.0. On an HDR
  display, tell us where the brightest parts start to clip.
- **Hold C on HDR files.** Switching between As macOS Shows It and Reference should be instant, with no
  flash of the wrong picture.
- **SDI and HDMI output** with HLG and PQ: should be exactly as in 0.9.0.

**Reporting a problem:** Help ▸ Export Diagnostics… saves a report we can read (no license details, and
no file names unless you tick the box). For a picture problem, Help ▸ Export Frame for Support… saves the
frame itself.

**New → Color** (no New section yet; add `## New` before Improved, as in 0.9.0):

- **Dolby Vision in the Inspector.** A file that carries Dolby Vision now says so, with its profile, its
  level and what Manifold shows. For example: "Profile 8.4 (level 7) · HLG base layer shown; DV metadata
  not applied". Manifold shows the standard picture inside the file and does not apply Dolby Vision
  itself.
- **A warning for Dolby Vision files Manifold can't show.** A profile 5 file (common for streaming
  masters), or any Dolby Vision file with no standard picture inside, now puts a warning across the top
  of the window: Manifold can't display it correctly. The Inspector says the same. Close the warning and
  it stays closed until you open another file. Profile 8 and 7 files, whose standard picture Manifold
  shows correctly, get no warning.

**Fixed → Color:**

- **Switching display modes changes the picture in one step.** The new mode's color settings and the
  repainted picture now reach the screen together. Before, they were sent a few milliseconds apart, so
  for a moment the old picture could be shown with the new mode's settings.
- **A false warning on every display-mode change is gone** (tester-facing; it only shows in
  diagnostics). Diagnostics reported that a frame had been shown with the wrong color each time the
  display mode or a color override changed. None was: the warning was counting the wrong thing. It still
  reports a real late color change when a file opens.

**Fixed → Interface and shortcuts:**

- **Window positions no longer pile up in Manifold's settings.** Every update saved the main window's
  position under a new name and never read the old ones. It now saves it under one fixed name that
  stays the same from update to update. Your window's saved position is reset once when you update to
  0.9.1, and from then on it is kept.

**Fixed → Licensing and privacy:**

- **About Manifold ▸ Licences now gives NDI's licensing page.** The links inside NDI's own license
  notice use NDI's short links, which have been down since October 29. The notice still ships exactly as
  NDI wrote it; About now says so and gives NDI's licensing page instead. The NDI SDK License Agreement
  itself is included in the NDI SDK download.
